## Projets

### MonJobTracker — SaaS de suivi de candidatures
Application web qui aide les étudiants à suivre leurs candidatures de stage et d'alternance : tableau en glisser-déposer, inscription par email ou Google, tableau de bord de statistiques et rappels.
`React` `Next.js` `Tailwind CSS` · [monjobtracker.app](https://monjobtracker.app)

### Sentinel X — Détection et observabilité d'une application web
Mise en place d'une chaîne de détection d'attaques avec Wazuh (règles personnalisées, alertes) et d'une supervision avec Prometheus et Grafana, sur une application conteneurisée. Projet EPITECH en équipe de 3.
`Wazuh` `Prometheus` `Grafana` `Docker`

### Persona — Assistant IA de veille personnalisée
Chef de projet. Chatbot unique avec authentification par code envoyé par email, agent IA limité aux données de l'utilisateur connecté, et newsletter programmée qui filtre et résume l'actualité selon les centres d'intérêt de chacun. Prise en compte du RGPD (consentement, désinscription, suppression des données).
`n8n` `Google Gemini` `Docker` `Agents IA`

### Codename — Sécurité des LLM
Agent local qui protège un mot de passe secret, et boîte à outils de 5 attaques par injection de prompt pour tester sa résistance, puis renforcement de l'agent.
`Ollama` `Python` `Prompt injection`

### DMZ — Jeu 2D en Java
Jeu de défense sur le thème de la cybersécurité : un serveur central attaqué de tous les côtés, et le joueur doit choisir la bonne défense face à chaque type d'attaque. Conçu en programmation orientée objet.
`Java` `POO`

### SecureVault — Projet personnel de sécurité
Application Java autour de la protection et du stockage sécurisé de données.
`Java`

### HydroTrack — Plateforme IoT d'arrosage intelligent
Chef de projet. Un capteur d'humidité relié à un ESP32 mesure le sol ; les mesures sont croisées avec la météo pour prévenir l'utilisateur quand il faut arroser. Historique et suivi sur un tableau de bord web.
`ESP32` `Node-RED` `Supabase (PostgreSQL)` `JavaScript` `OpenWeather API` `Vercel`

### Infrastructures réseau
- Réseau segmenté sous Packet Tracer (VLAN, ACL, Port-Security) avec scripts d'automatisation en Python.
- Infrastructure d'entreprise virtualisée : GNS3, ESXi, pfSense, Active Directory, DHCP, serveurs de fichiers et web.

`Réseau` `Linux` `pfSense` `Active Directory` `Python`
